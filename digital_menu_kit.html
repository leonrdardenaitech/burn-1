Straight answers

Is this a drag-and-drop builder?

No. It's a text file — you find the old dish, type over it with the new one. The only drag-and-drop is uploading the finished folder to your host.

Do I need Netlify specifically?

No. It's static HTML/CSS — deploy it anywhere that serves files: Netlify, GitHub Pages, Firebase Hosting, your existing host.

How long do updates take after setup?

About 2 minutes — edit the text, push the same folder again. Same URL, same printed QR code.
